# hon-dannytunz-link-in-bio

This repository contains a mobile-first link-in-bio page for Hon. Dannytunz.

Files included:
- index.html
- styles.css
- script.js

Place your images in the assets/ folder with the exact filenames below (case-sensitive):
- assets/portrait.jpg       (studio portrait - Image 3)
- assets/logo.png           (emblem/logo - Image 4)
- assets/music-flyer.jpg    (music tutoring flyer - Image 1)
- assets/services-catalog.jpg (business services catalog - Image 2)

How to publish with GitHub Pages:
1. Upload the image files to the `assets/` folder (via the GitHub web UI or git).
2. In the repository settings -> Pages, set the source to the `main` branch and root (/).
3. Save; GitHub will provide the site URL. The expected URL will be:
   `https://adelekedaniel63-code.github.io/hon-dannytunz-link-in-bio/`
